# Paramdex data

Vendor the Paramdex `ER/Defs` (and other games' defs as needed) XML here — data only, no code. Language-agnostic, so it can be copied directly from `elden_magic_mod/external/Paramdex` without translation. `souls-format` reads these to decode param rows; see `docs/planning/bootstrap-checklist.md` step 2 for the specific validation case (`SpEffectParam` row 835) to check once this data is in place.
